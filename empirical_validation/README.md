# Empirical Analysis Dataset Access

This page provides brief instructions for requesting or obtaining access to the datasets used in the empirical analysis. Access procedures may change, so researchers should always confirm the current requirements on the official dataset website.

## Dataset Access

### ADNI
**Access:** https://adni.loni.usc.edu/data-samples/adni-data/  
Access is controlled. Researchers must create a LONI/IDA account, accept the applicable data-use agreement, and submit a data-access application describing the proposed research.

### PREVENT-AD
**Access:** https://registeredpreventad.loris.ca/  
Access to the registered repository is application-based. Researchers must request an account and agree to the relevant data-use conditions. The registered repository includes PET imaging data.

### DLBS
**Access:** https://openneuro.org/datasets/ds004856  
The DLBS dataset is openly available through OpenNeuro and can be downloaded without a formal data-access application.

### HABS
**Access:** https://habs.mgh.harvard.edu/researchers/  
Access is controlled and managed through Synapse. Researchers must create an account, request access to the dataset, and accept the applicable HABS data-use agreement.

### UK Biobank
**Access:** https://www.ukbiobank.ac.uk/use-our-data/apply-for-access/  
Access is controlled. Eligible researchers must submit a research application and complete the required data-use agreements and access procedures. (Applications are currently closed; October 2026)

### LCBC
**Access:** https://www.oslobrains.no/  
Data access is generally arranged on a project- or collaboration-specific basis. Researchers should contact LCBC directly (k.b.walhovd[at]psykologi.uio.no) to discuss data availability, approvals, and applicable data-sharing requirements.
